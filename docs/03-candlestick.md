# ০৩ — ক্যান্ডেলস্টিক পড়া

> আপনি চেয়েছিলেন "ক্যান্ডেল দেখে প্রেডিকশন"। এই ফাইলে ক্যান্ডেল পড়া শেখাচ্ছি — কিন্তু শেষে একটা অংশ আছে যেটা সবচেয়ে গুরুত্বপূর্ণ: **কেন একা ক্যান্ডেল দিয়ে প্রেডিকশন হয় না।** সেটাও পড়বেন।

---

## একটা ক্যান্ডেল কী বলে

প্রতিটা ক্যান্ডেল একটা নির্দিষ্ট সময়ের **৪টা তথ্য** দেখায় (OHLC):

- **Open** — সময়টা শুরুর দাম
- **High** — সর্বোচ্চ দাম
- **Low** — সর্বনিম্ন দাম
- **Close** — সময়টা শেষের দাম

```
       │  ← Upper wick (High পর্যন্ত)
     ┌─┴─┐
     │   │  ← Body (Open আর Close এর মাঝে)
     │   │
     └─┬─┘
       │  ← Lower wick (Low পর্যন্ত)
```

### সবুজ vs লাল

```
   সবুজ (Bullish)          লাল (Bearish)
   Close > Open            Close < Open
   দাম বেড়েছে              দাম কমেছে

       │ High                   │ High
     ┌─┴─┐ Close             ┌─┴─┐ Open
     │   │                   │   │
     │   │                   │   │
     └─┬─┘ Open              └─┬─┘ Close
       │ Low                    │ Low
```

---

## Body আর Wick কী বলে

এটাই ক্যান্ডেল পড়ার মূল কথা:

| যা দেখছেন | যা বোঝায় |
|-----------|----------|
| **লম্বা body** | একপক্ষ (ক্রেতা বা বিক্রেতা) পুরো সময়টা নিয়ন্ত্রণে ছিল |
| **ছোট body** | কেউই জিততে পারেনি, দ্বিধা |
| **লম্বা উপরের wick** | দাম উপরে উঠেছিল কিন্তু **বিক্রেতারা নামিয়ে দিয়েছে** |
| **লম্বা নিচের wick** | দাম নিচে নেমেছিল কিন্তু **ক্রেতারা তুলে নিয়েছে** |
| **wick নেই** | একমুখী, শক্তিশালী নড়াচড়া |

> **মূল কথা:** Wick দেখায় দাম **কোথায় যেতে চেয়েছিল কিন্তু পারেনি**। ওখানেই বিপরীত পক্ষ অপেক্ষা করছিল। সেটাই গুরুত্বপূর্ণ তথ্য।

---

## গুরুত্বপূর্ণ প্যাটার্নগুলো

### ১. Doji — দ্বিধা

```
       │
     ──┼──   ← Open আর Close প্রায় একই
       │
```

Open আর Close প্রায় একই। ক্রেতা-বিক্রেতা সমান শক্তিশালী।

**মানে:** সিদ্ধান্তহীনতা। একটা শক্তিশালী ট্রেন্ডের **শেষে** দেখা দিলে ট্রেন্ড ক্লান্ত হয়ে পড়ার ইঙ্গিত।

**সতর্কতা:** মাঝামাঝি অবস্থায় Doji মানে কিছুই না। প্রেক্ষাপট লাগবে।

---

### ২. Hammer — নিচে ক্রেতাদের প্রতিরোধ

```
     ┌─┐   ← ছোট body উপরে
     └─┘
       │
       │   ← লম্বা নিচের wick (body এর ২x+)
       │
```

**যা ঘটেছে:** বিক্রেতারা দাম অনেক নিচে নামিয়েছিল, কিন্তু ক্রেতারা ঝাঁপিয়ে পড়ে প্রায় পুরোটা ফিরিয়ে এনেছে।

**কখন অর্থপূর্ণ:** একটা **নামতে থাকা ট্রেন্ডের নিচে**, একটা **সাপোর্ট লেভেলে**। তখন এটা সম্ভাব্য উল্টে যাওয়ার (reversal) ইঙ্গিত।

**কখন অর্থহীন:** চার্টের মাঝখানে, কোনো লেভেল ছাড়া। তখন এটা শুধু একটা ক্যান্ডেল।

---

### ৩. Shooting Star — উপরে বিক্রেতাদের প্রতিরোধ

```
       │
       │   ← লম্বা উপরের wick
       │
     ┌─┐   ← ছোট body নিচে
     └─┘
```

Hammer এর উল্টো। দাম উপরে উঠেছিল, বিক্রেতারা নামিয়ে দিয়েছে।

**কখন অর্থপূর্ণ:** একটা **উঠতে থাকা ট্রেন্ডের চূড়ায়**, একটা **রেজিস্ট্যান্স লেভেলে**।

---

### ৪. Engulfing — নিয়ন্ত্রণ হাতবদল

**Bullish Engulfing:**
```
   ┌─┐  ┌───┐
   │ │  │   │   ← সবুজ ক্যান্ডেল আগের লাল
   └─┘  │   │      ক্যান্ডেলকে পুরো গিলে ফেলেছে
        └───┘
   লাল   সবুজ
```

আগের ক্যান্ডেলের পুরো body দ্বিতীয় ক্যান্ডেলের body এর ভেতরে ঢুকে গেছে, এবং রং উল্টো।

**মানে:** নিয়ন্ত্রণ হাতবদল হয়েছে — জোরের সাথে।

**Bearish Engulfing** — একই জিনিস উল্টোদিকে, উঠতে থাকা ট্রেন্ডের চূড়ায়।

এটা সবচেয়ে নির্ভরযোগ্য প্যাটার্নগুলোর একটা — **যদি সঠিক জায়গায় হয়।**

---

### ৫. Marubozu — একতরফা

```
   ┌───┐   ← কোনো wick নেই
   │   │
   │   │
   └───┘
```

Wick নেই মানে এক পক্ষ পুরো সময়টা সম্পূর্ণ নিয়ন্ত্রণে ছিল। শক্তিশালী ট্রেন্ডের ইঙ্গিত।

---

## প্যাটার্ন যথেষ্ট না — প্রেক্ষাপট লাগবে

এখানেই ৯০% শিক্ষানবিশ ভুল করে। তারা প্যাটার্ন মুখস্থ করে, তারপর চার্টে সব জায়গায় প্যাটার্ন "দেখতে" শুরু করে।

**একটা Hammer একা কিছুই না। একটা Hammer একটা গুরুত্বপূর্ণ সাপোর্ট লেভেলে, একটা নামতে থাকা ট্রেন্ডের শেষে, বেশি ভলিউমের সাথে — সেটা একটা তথ্য।**

### প্রেক্ষাপটের ৩টা স্তম্ভ

#### ক) Trend — বাজার কোন দিকে যাচ্ছে?

```
  Uptrend:  উঁচু চূড়া, উঁচু তলা
            (Higher Highs, Higher Lows)
                        ╱╲
                  ╱╲   ╱  ╲
            ╱╲   ╱  ╲ ╱
           ╱  ╲ ╱    ╲╱
          ╱    ╲╱

  Downtrend: নিচু চূড়া, নিচু তলা
            (Lower Highs, Lower Lows)
          ╲    ╱╲
           ╲  ╱  ╲ ╱╲
            ╲╱    ╲╱  ╲   ╱╲
                       ╲ ╱  ╲
                        ╲╱
```

**নিয়ম: ট্রেন্ডের বিরুদ্ধে ট্রেড করবেন না।** Uptrend এ শুধু কেনার সুযোগ খুঁজুন।

#### খ) Support / Resistance — যেখানে দাম আগে থেমেছে

- **Support** — যে দামে ক্রেতারা বারবার ঢুকে দাম তুলে ধরেছে (মেঝে)
- **Resistance** — যে দামে বিক্রেতারা বারবার দাম আটকে দিয়েছে (ছাদ)

এই লেভেলগুলো আঁকতে শিখুন। **প্যাটার্ন শুধু এই লেভেলগুলোতেই গুরুত্বপূর্ণ।**

চার্টে একটা লেভেল আঁকার নিয়ম: দাম অন্তত ২-৩ বার ওখানে থেমেছে বা ঘুরে গেছে।

#### গ) Volume — কতজন অংশ নিল

বেশি ভলিউমে হওয়া প্যাটার্ন অনেক বেশি অর্থবহ। কম ভলিউমে হওয়া প্যাটার্ন সাধারণত ফাঁদ।

## একটা সত্যিকারের সেটআপ কেমন দেখায়

সব মিলিয়ে, একটা যুক্তিসঙ্গত ট্রেড আইডিয়ার সব শর্ত পূরণ হওয়া দরকার:

```
✅ Daily চার্টে Uptrend (Higher Highs, Higher Lows)
✅ দাম নেমে এসে একটা পরিচিত Support লেভেল ছুঁয়েছে
✅ ওই লেভেলে একটা Bullish Engulfing বা Hammer তৈরি হয়েছে
✅ ভলিউম স্বাভাবিকের চেয়ে বেশি
✅ আগামী ২৪ ঘণ্টায় বড় কোনো খবর নেই
✅ Stop Loss বসানোর একটা যৌক্তিক জায়গা আছে (support এর ঠিক নিচে)
✅ Stop থেকে Target এর দূরত্ব কমপক্ষে ১:২
```

**৭টার মধ্যে ৫টা মিললে — ট্রেড নেবেন না।** পরেরটার জন্য অপেক্ষা করুন। এই অপেক্ষার ক্ষমতাটাই ট্রেডিং এর আসল স্কিল।

## এখন সবচেয়ে গুরুত্বপূর্ণ অংশ

### ক্যান্ডেল ভবিষ্যৎ বলে না

একটা ক্যান্ডেল হলো **যা ঘটে গেছে তার রেকর্ড**। এটা যা ঘটবে তার রেকর্ড না।

সব প্যাটার্ন বই আপনাকে বলবে "Bullish Engulfing মানে দাম বাড়বে।" বাস্তবে Bullish Engulfing এর পর দাম বাড়ে হয়তো **৫০-৬০% ক্ষেত্রে।** এটা কয়েন টসের চেয়ে সামান্য ভালো।

**তাহলে ট্রেডাররা টাকা কীভাবে বানায়?**

ধরুন আপনার সেটআপ ৫০% সময় কাজ করে (কয়েন টস!), কিন্তু:
- যখন ভুল হয়, আপনি **$১** হারান (Stop Loss)
- যখন ঠিক হয়, আপনি **$৩** জেতেন (১:৩ R:R)

১০ ট্রেডে: ৫টা ভুল = −$৫। ৫টা ঠিক = +$১৫। **নিট +$১০।**

**প্রেডিকশনটা গুরুত্বপূর্ণ না। প্রেডিকশন ভুল হলে কত হারাবেন সেটা গুরুত্বপূর্ণ।**

এটাই আসল রহস্য। কোনো গোপন প্যাটার্ন নেই, কোনো গোপন ইন্ডিকেটর নেই। শুধু: **ছোট হারুন, বড় জিতুন, আর যথেষ্ট বার খেলুন।**

---

### তাই আমি প্রেডিকশন দেব না

আপনি চেয়েছিলেন আমি ক্যান্ডেল দেখে প্রেডিকশন দিই। সোজা উত্তর: **আমি পারব না, এবং কেউ পারে না।**

যদি পারতাম, আমি আপনাকে বলতাম না — আমি নিজেই ট্রেড করতাম।

**এটাই স্ক্যাম চেনার সবচেয়ে সহজ নিয়ম:** যে লোক সত্যিই পরের ক্যান্ডেল জানে, সে আপনাকে $২০/মাসে সিগন্যাল বেচবে না। সে চুপচাপ বিলিয়নেয়ার হয়ে যাবে।

## এই সপ্তাহের অনুশীলন

টাকা লাগবে না, ট্রেড করতে হবে না:

1. **TradingView** খুলুন → BTCUSD বা AAPL → **Daily** টাইমফ্রেম
2. **Support/Resistance আঁকুন** — যেখানে দাম অন্তত ৩ বার ঘুরেছে (সোজা লাইন টুল)
3. **ট্রেন্ড চিহ্নিত করুন** — Higher Highs না Lower Lows?
4. **প্যাটার্ন খুঁজুন** ঠিক ওই লেভেলগুলোতে — Hammer, Engulfing
5. **চার্ট ঢেকে ফেলুন** প্যাটার্নের পরে, লিখুন "আমার মনে হয় উপরে/নিচে যাবে"
6. **খুলে দেখুন** কী হয়েছিল
7. **স্কোর রাখুন** — ৫০ বার করুন

৫০ বার পর আপনি জানবেন আপনি আসলে কত % সঠিক। বেশিরভাগ মানুষ আবিষ্কার করে তারা ৫০% এর কাছাকাছি। **এটা জানা খুব মূল্যবান** — কারণ তখন আপনি বুঝবেন খেলাটা প্রেডিকশনের না, রিস্ক ম্যানেজমেন্টের।
