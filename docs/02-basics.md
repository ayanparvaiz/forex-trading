# ০২ — মৌলিক জিনিসগুলো

---

## ট্রেডিং আসলে কী

আপনি একটা জিনিস কম দামে কিনে বেশি দামে বেচার চেষ্টা করছেন (অথবা উল্টোটা — বেশি দামে বেচে কম দামে কিনে)। ব্যস। এতটুকুই।

**কিন্তু গুরুত্বপূর্ণ ব্যাপারটা হলো:** বাজারে প্রতিটা ট্রেডে একজন কিনছে আর একজন বেচছে। একজন ভুল করছে। প্রশ্ন হলো — আপনি যখন কিনছেন, **উল্টোদিকে কে বেচছে?**

বেশিরভাগ সময় উল্টোদিকে থাকে একটা ব্যাংক, একটা হেজ ফান্ড, বা একটা অ্যালগরিদম — যার কাছে আপনার চেয়ে ভালো ডেটা, দ্রুত কানেকশন, আর বেশি পুঁজি আছে। এটা মনে রাখলে অনেক ভুল এড়ানো যায়।

---

## কোন বাজারগুলো আছে

### ১. Forex (মুদ্রা)
EUR/USD, GBP/USD, USD/JPY — এক দেশের মুদ্রার বিপরীতে আরেক দেশের।

- **খোলা থাকে:** সোম-শুক্র, ২৪ ঘণ্টা
- **$১০০ এ চলে?** টেকনিক্যালি হ্যাঁ (মাইক্রো লট), কিন্তু লিভারেজ ছাড়া প্রায় অসম্ভব
- **সমস্যা:** লিভারেজ এখানেই মানুষ মারে। বাংলাদেশ/ভারতে আইনি জটিলতা আছে — [05-platform.md](05-platform.md) দেখুন

### ২. Crypto (ক্রিপ্টোকারেন্সি)
Bitcoin, Ethereum, ইত্যাদি।

- **খোলা থাকে:** ২৪/৭, সারা বছর
- **$১০০ এ চলে?** হ্যাঁ — ভগ্নাংশে কেনা যায় ($১০ এর Bitcoin কেনা যায়)
- **সমস্যা:** প্রচণ্ড ভোলাটাইল, বাংলাদেশে আইনি অবস্থা প্রতিকূল, স্ক্যামে ভরা

### ৩. Stocks (শেয়ার)
কোম্পানির মালিকানার অংশ। DSE (ঢাকা), NSE/BSE (ভারত), NYSE/NASDAQ (আমেরিকা)।

- **খোলা থাকে:** নির্দিষ্ট সময়, কর্মদিবসে
- **$১০০ এ চলে?** স্থানীয় বাজারে কষ্টকর, আমেরিকান ফ্র্যাকশনাল শেয়ারে হ্যাঁ
- **সুবিধা:** সবচেয়ে ধীর, সবচেয়ে কম বিপজ্জনক, শেখার জন্য সবচেয়ে ভালো
- **সমস্যা:** ধৈর্য লাগে, "রোজ প্রফিট" হয় না

### ৪. Binary Options ❌
Quotex, Olymp Trade, IQ Option, Binomo, Pocket Option।

**এগুলো ট্রেডিং না — জুয়া।** এবং এমন জুয়া যেখানে হাউস আপনার বিরুদ্ধে বাজি ধরছে। EU, UK, ভারতে নিষিদ্ধ। বিস্তারিত [06-scam-alert.md](06-scam-alert.md) এ।

**এগুলোতে কখনও যাবেন না।** বাংলা ইউটিউব/ফেসবুকে এগুলোরই সবচেয়ে বেশি প্রচার — কারণ রেফারেল কমিশন দেয়।

## যে শব্দগুলো জানতেই হবে

### দাম সংক্রান্ত

| শব্দ | মানে |
|------|------|
| **Bid** | ক্রেতারা যে দামে কিনতে রাজি (আপনি এই দামে বেচবেন) |
| **Ask** | বিক্রেতারা যে দামে বেচতে রাজি (আপনি এই দামে কিনবেন) |
| **Spread** | Bid আর Ask এর পার্থক্য — **এটা আপনার খরচ** |
| **Liquidity** | কত সহজে কেনা-বেচা যায়। কম liquidity = বেশি spread |
| **Volatility** | দাম কত দ্রুত ওঠানামা করে |

> **Spread কেন গুরুত্বপূর্ণ:** আপনি কেনার সাথে সাথেই spread এর পরিমাণ লোকসানে থাকেন। ছোট অ্যাকাউন্টে এটা মারাত্মক।

### পজিশন সংক্রান্ত

| শব্দ | মানে |
|------|------|
| **Long / Buy** | দাম বাড়বে ধরে কেনা |
| **Short / Sell** | দাম কমবে ধরে বেচা (না থাকা জিনিস ধার করে বেচা) |
| **Position size** | কত পরিমাণ কিনলেন |
| **Entry** | যে দামে ঢুকলেন |
| **Exit** | যে দামে বেরোলেন |

### ঝুঁকি সংক্রান্ত — **এগুলোই সবচেয়ে জরুরি**

| শব্দ | মানে |
|------|------|
| **Stop Loss (SL)** | অটো-বেচার অর্ডার, লোকসান আটকাতে। **এটা ছাড়া কখনও ট্রেড না** |
| **Take Profit (TP)** | অটো-বেচার অর্ডার, লাভ ঘরে তুলতে |
| **Risk : Reward (R:R)** | কত হারাতে রাজি vs কত জিততে চান। ন্যূনতম ১:২ |
| **Drawdown** | সর্বোচ্চ থেকে কত নিচে নেমেছে অ্যাকাউন্ট |
| **Leverage** | ধার করা টাকা। **১০x মানে লাভ ১০ গুণ, লোকসানও ১০ গুণ** |
| **Margin call** | ব্রোকার বলছে টাকা ঢালো নইলে পজিশন বন্ধ |
| **Liquidation** | ব্রোকার জোর করে আপনার পজিশন বন্ধ করে দিল। অ্যাকাউন্ট শূন্য |

---

## Leverage — এই অংশটা দুবার পড়ুন

Leverage হলো ব্রোকারের ধার দেওয়া টাকা, যাতে আপনি আপনার পুঁজির চেয়ে বড় পজিশন নিতে পারেন।

**উদাহরণ:** $১০০ আছে, ১০x লিভারেজ নিলেন = $১,০০০ এর পজিশন।

| দাম নড়ল | আপনার অ্যাকাউন্টে প্রভাব |
|----------|------------------------|
| +১% | +$১০ (১০% লাভ) 😀 |
| −১% | −$১০ (১০% লোকসান) |
| −৫% | −$৫০ (অর্ধেক শেষ) |
| **−১০%** | **−$১০০ — অ্যাকাউন্ট শূন্য** 💀 |

১০০x লিভারেজে **দাম মাত্র ১% উল্টো গেলেই** অ্যাকাউন্ট শূন্য। Bitcoin এ ১% নড়তে কয়েক মিনিট লাগে।

**নিয়ম: প্রথম এক বছর লিভারেজ = ০। একেবারে শূন্য।**

লোকে লিভারেজ নেয় কারণ $১০০ দিয়ে "রোজ ২%" করার আর কোনো উপায় নেই। আর ঠিক এই কারণেই তারা অ্যাকাউন্ট উড়িয়ে দেয়।

## টাইমফ্রেম

চার্টে প্রতিটা ক্যান্ডেল কত সময়ের প্রতিনিধিত্ব করে:

| টাইমফ্রেম | ১টা ক্যান্ডেল = | কাদের জন্য |
|----------|----------------|------------|
| M1, M5 | ১/৫ মিনিট | Scalper — **শিক্ষানবিশদের জন্য বিষ** |
| M15, H1 | ১৫ মিনিট / ১ ঘণ্টা | Day trader |
| H4, D1 | ৪ ঘণ্টা / ১ দিন | Swing trader — **শেখার জন্য সবচেয়ে ভালো** |
| W1, MN | সপ্তাহ / মাস | Investor |

**শিক্ষানবিশ হিসেবে D1 (দৈনিক) আর H4 দিয়ে শুরু করুন।**

কারণ: ছোট টাইমফ্রেমে ৯০% নড়াচড়া হলো এলোমেলো শব্দ (noise)। M1 চার্টে আপনি প্যাটার্ন দেখছেন ভাবলেও আসলে দেখছেন এলোমেলোতা। আর ছোট টাইমফ্রেমে ফি অনেক বেশি লাগে কারণ ট্রেড বেশি হয়।

"রোজ ২-৩%" এর লক্ষ্য মানুষকে M1/M5 এ ঠেলে দেয় — যেখানে হারার সম্ভাবনা সবচেয়ে বেশি।

## দুই ধরনের বিশ্লেষণ

**Technical Analysis (TA)** — দাম আর চার্ট দেখে সিদ্ধান্ত। ক্যান্ডেল, সাপোর্ট-রেজিস্ট্যান্স, ইন্ডিকেটর। আপনি এটাই শিখবেন।

**Fundamental Analysis (FA)** — কোম্পানির আয়, দেশের সুদের হার, খবর দেখে সিদ্ধান্ত।

শিক্ষানবিশ হিসেবে TA শিখুন, কিন্তু **FA কে উপেক্ষা করবেন না** — বড় খবর (সুদের হার ঘোষণা, আয়ের রিপোর্ট) যেকোনো টেকনিক্যাল প্যাটার্ন এক সেকেন্ডে ভেঙে দেয়। ক্যালেন্ডার দেখে বড় খবরের সময় ট্রেড এড়িয়ে চলুন।
