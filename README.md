# শিখি — Shikhi

**বাংলায় ট্রেডিং শেখার অ্যাপ।** ডেমো টাকা দিয়ে প্র্যাকটিস, আসল হিসাব, আসল নিয়ম — আসল ঝুঁকি ছাড়া।

> A Bengali-first trading education app. Practice with demo money, learn real risk
> management, and get ranked on **discipline — not profit**.

---

## কেন আরেকটা ট্রেডিং সিমুলেটর?

কারণ এটা সিমুলেটর না, **শেখার অ্যাপ**।

বেশিরভাগ সিমুলেটর আপনাকে $১,০০,০০০ ডেমো ব্যালেন্স দেয়। মানুষ এক ট্রেডে ৫০% লাগায়, জিতে যায়,
আত্মবিশ্বাস নিয়ে আসল মার্কেটে নামে — আর $১০০ হারিয়ে ফেলে। সিমুলেটরটা তাকে জুয়া শিখিয়েছে,
ট্রেডিং না।

শিখি অন্যভাবে কাজ করে:

| বেশিরভাগ অ্যাপ | শিখি |
|---|---|
| $১,০০,০০০ ডেমো ব্যালেন্স | **$১০০ দিয়ে শুরু** — বাস্তব সংখ্যা, বাস্তব শিক্ষা |
| স্টপ লস অপশনাল | **স্টপ লস ছাড়া ট্রেড হবে না** |
| লাভ ডলারে দেখায় | **R-multiple এ দেখায়** (+2.3R / −1.0R) |
| লিডারবোর্ড = সবচেয়ে বেশি লাভ | **লিডারবোর্ড = সবচেয়ে ভালো ডিসিপ্লিন** |
| স্প্রেড/ফি ইগনোর করে | **স্প্রেড, ফি, স্লিপেজ সিমুলেট করে** |
| ইংরেজি | **বাংলা** |

লিডারবোর্ড লাভ দিয়ে র‍্যাংক করলে অ্যাপটা ক্যাসিনো হয়ে যায় — শুধু টাকা ছাড়া। তাই এখানে
র‍্যাংক হয় **ডিসিপ্লিন স্কোর** দিয়ে: নিয়ম মেনেছেন কিনা, স্টপ লস দিয়েছেন কিনা, রিস্ক
১%-এর নিচে রেখেছেন কিনা, জার্নাল লিখেছেন কিনা।

## কী আছে

- **📊 ট্রেড** — EUR/USD, GBP/USD লাইভ চার্ট। এন্ট্রি, স্টপ, টার্গেট — স্টপ ছাড়া বাটন কাজ করবে না।
- **🧮 ক্যালকুলেটর** — পজিশন সাইজ, রিস্ক %, R:R অনুপাত — সব লাইভ, স্লাইডার ঘোরালেই আপডেট।
- **📓 জার্নাল** — প্রতি ট্রেডের R-multiple, expectancy, win rate, max drawdown, recovery math।
- **🏆 কমিউনিটি** — ডিসিপ্লিন লিডারবোর্ড, ট্রেড জার্নাল ফিড, কোহর্ট ব্যাচ।
- **⏪ মার্কেট রিপ্লে** — পুরোনো ক্যান্ডেল চালিয়ে প্র্যাকটিস (planned)।
- **📚 পাঠ** — [`docs/`](docs/) এর পুরো কোর্স অ্যাপের ভেতরেই।

## Tech stack

| Layer | Choice |
|---|---|
| App | Flutter 3.44 (iOS + Android) |
| Backend | Firebase — Auth, Firestore, Cloud Functions |
| Market data | [Twelve Data](https://twelvedata.com/forex) free tier (forex OHLC) |
| Charts | Custom `CustomPainter` — no chart dependency |

### চালাতে

```bash
cd app
flutter pub get
flutter run
```

বর্তমানে UI প্রোটোটাইপ মক ডেটা দিয়ে চলে — Firebase বা API key ছাড়াই রান করবে।

## ⚠️ জরুরি কথা

এটা একটা **শিক্ষামূলক সিমুলেটর**। এখানে কোনো আসল টাকা নেই, কোনো ব্রোকার কানেকশন নেই,
কোনো ডিপোজিট নেই।

- এটা **বিনিয়োগ পরামর্শ না**। কোন ট্রেড নেবেন সেটা এই অ্যাপ বলবে না।
- এখানে কোনো **সিগন্যাল, VIP গ্রুপ, বা ব্রোকার রেফারেল** নেই — এবং কখনো থাকবে না।
- ডেমোতে লাভ করা মানে আসল মার্কেটে লাভ করা না। [কেন, পড়ুন এখানে](docs/01-reality-check.md)।
- আপনার দেশে ফরেক্স/CFD ট্রেডিং বৈধ কিনা নিজে যাচাই করুন — [দেশ অনুযায়ী তথ্য](docs/05-platform.md)।
